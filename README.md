# Cuadre de Caja

Aplicación web sencilla para contar el efectivo de una caja por denominación.

## Denominaciones

Incluye las 12 denominaciones de euro desde **0,01 € hasta 50 €**, en orden ascendente:

**0,01 · 0,02 · 0,05 · 0,10 · 0,20 · 0,50 · 1 · 2 · 5 · 10 · 20 · 50 €**

Para cada denominación se introducen dos cantidades:

- **Caja fuerte**
- **Caja menor**

La aplicación calcula automáticamente el **Total** de cada denominación y el **Total en caja**.

Los datos se conservan en el navegador mediante almacenamiento local y pueden borrarse con **Reiniciar**.
